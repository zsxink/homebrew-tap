# zsxink Homebrew Tap

[简体中文](README.md)

This tap provides Homebrew packages for MarkFlow and MusicTag.

## MarkFlow

[MarkFlow](https://github.com/zsxink/MarkFlow) is a modern Markdown editor with WYSIWYG and source modes.

Install:

```bash
brew install zsxink/tap/markflow
```

Update:

```bash
brew update && brew upgrade markflow
```

MarkFlow is maintained automatically by its release workflow.

## MusicTag

[MusicTag](https://github.com/zsxink/MusicTag) is a desktop app for editing metadata, cover art, and lyrics in local music files.

Install:

```bash
brew install zsxink/tap/musictag
```

Update:

```bash
brew update && brew upgrade --cask musictag
```

The public tap does not require a GitHub account. New MusicTag versions are available after a stable release is published and synced to this tap.
