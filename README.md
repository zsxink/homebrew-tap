# Homebrew tap for MarkFlow and MusicTag

- [MarkFlow](https://github.com/zsxink/MarkFlow) — Modern Markdown editor with WYSIWYG and source mode.
- [MusicTag](https://github.com/zsxink/MusicTag) — Desktop app for editing metadata, cover art, and lyrics in local music files.

## MarkFlow

### Install

```bash
brew install zsxink/tap/markflow
```

### Update

```bash
brew update && brew upgrade markflow
```

MarkFlow is maintained automatically by its release workflow.

## MusicTag

### Install

```bash
brew install zsxink/tap/musictag
```

### Update

```bash
brew update && brew upgrade --cask musictag
```

The public tap does not require a GitHub account. New MusicTag versions become available after the stable GitHub release is published and synced to this tap.
