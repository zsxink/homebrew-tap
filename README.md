# zsxink Homebrew Tap

[English](README.en.md)

本 tap 提供 MarkFlow 和 MusicTag 的 Homebrew 安装包。

## MarkFlow

[MarkFlow](https://github.com/zsxink/MarkFlow) 是一款现代 Markdown 编辑器，支持所见即所得和源码模式。

安装：

```bash
brew install zsxink/tap/markflow
```

更新：

```bash
brew update && brew upgrade markflow
```

MarkFlow 由其 release workflow 自动维护。

## MusicTag

[MusicTag](https://github.com/zsxink/MusicTag) 是一款用于编辑本地音乐文件元数据、封面和歌词的桌面应用。

安装：

```bash
brew install zsxink/tap/musictag
```

更新：

```bash
brew update && brew upgrade --cask musictag
```

公开 tap 无需 GitHub 账号即可使用。MusicTag 稳定版发布并同步到 tap 后，即可获取新版本。
